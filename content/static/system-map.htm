Stocks and flows

Boxes are stocks (things that accumulate), pipes with valves are flows (rates per year), clouds are model boundaries. The italic lines under each flow list the variables from the causal map that set its rate, which links each stock-and-flow chain to the loops. Together these are the skeleton for a quantitative model (Vensim, Stella, PySD).
